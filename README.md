---

## 1. Continuous Monitoring Capabilities

This command-line tool audits TLS certificate health, trust chain validity, and expiration timelines for New Zealand organisations:

* **CERT NZ Alignment:** Audits transport layer encryption in alignment with CERT NZ Critical Controls and NZISM.
* **Proactive Expiration Tracking:** Monitors expiration dates to maintain uninterrupted encrypted communications.
* **Cipher & CA Verification:** Verifies TLS 1.3 implementation and authenticates issuing Certificate Authorities.
* **Lightweight Native Execution:** Requires no external libraries, running directly on standard Python installations.

---

## 2. Quick Start Guide

Execute a ferramenta diretamente via Python sem necessidade de instalar dependências externas:

```bash
python watchdog.py exemplo.com
```
